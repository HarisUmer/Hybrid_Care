# 🔧 Hybrid Care

**Multi-business web platform for hybrid-vehicle battery care & energy services.**

A React + TypeScript site (built on the Hashim Traders platform) supporting multiple business profiles from a shared, data-driven codebase.

## ✨ Features

- 🏢 **Multi-business, data-driven** — swap business profiles/content without touching layout code.
- ⚡ **Vite + React + TypeScript** for a fast, typed developer experience.
- 🎞️ **Framer Motion** animations and **Swiper** carousels.
- 🧭 **React Router** navigation, mobile-first responsive design.

## 🚀 Getting started

```bash
npm install
npm run dev        # start dev server
npm run build      # production build
npm run preview    # preview the build
```

## 🧱 Tech stack

`React` · `TypeScript` · `Vite` · `React Router` · `Framer Motion` · `Swiper` · `lucide-react`
